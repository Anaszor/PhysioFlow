# 🩺 فيزيو فلو (PhysioFlow) - نظام إدارة مراكز العلاج الطبيعي والتأهيل

نظام متكامل واحترافي مصمم خصيصاً لمراكز وعيادات العلاج الطبيعي والتأهيل الحركي، مبني باستخدام **ASP.NET Core 11 MVC** مع واجهات **Bootstrap 5.3 RTL** عصرية، ونظام مصادقة وصلاحيات متقدم **ASP.NET Core Identity** مع دعم كامل لقاعدة بيانات **PostgreSQL** وجاهزية فورية للنشر والاستضافة السحابية.

---

## 🌟 الميزات الرئيسية وفصل الأدوار (RBAC):

### 1. نظام المصادقة والصلاحيات (Authentication & Roles):
- **موظف الاستقبال (`Receptionist`):**
  - تسجيل المرضى الجدد وتعبئة استبيان تقييم الإصابة الأولي (`Intake`).
  - إدارة المواعيد وحجز الفترات الزمنية (`Timeslots`).
  - تأكيد حضور المريض بالاستقبال (تسجيل الوصول).
  - *محظور عليه التشخيص السريري أو اعتماد الجلسات الطبية.*
- **الطبيب / الأخصائي المعالج (`Doctor`):**
  - الفحص والتشخيص السريري وفحص المدى الحركي (`ROM` و `MMT`).
  - إنشاء الخطط العلاجية وتحديد الأجهزة والتمارين المنزلية.
  - **نموذج توثيق ما بعد الجلسة (Post-Session Clinical Form):** قياس شدة الألم (VAS 1-10)، التقنيات المنفذة، استجابة المريض، واعتماد إنجاز الجلسة.
  - *محظور عليه حجز الفترات أو تسجيل المرضى من الصفر.*
- **مدير النظام (`Admin`):**
  - كامل الصلاحيات الإدارية، وإدارة الطاقم والمستخدمين وتعيين الأدوار (`/Account/Users`).
- **المرضى (`Patients`):**
  - لا يمتلكون حسابات تسجيل دخول (تتم إدارة ملفاتهم من قِبل الفريق الطبي والاستقبال مباشرة).

---

### 3. خريطة الجسم ومقياس الألم التفاعلي:
- **خريطة تفاعلية لمجسم الجسم (Anatomical Body Map):** تحديد موضع الألم تشريحياً (العمود الفقري، الأطراف العلوية، الأطراف السفلية).
- **مقياس شدة الألم التفاعلي (VAS 1-10 Pain Scale):** منزلق ديناميكي ملون لتحديد درجة الألم.

### 4. جدولة المواعيد والفترات الزمنية (Timeslots):
- فترات تلقائية (صباحية، ظهيرة، مسائية - 45 دقيقة لكل جلسة).
- نظام ذكي لمنع التعارض والحجز المزدوج (Double-Booking Prevention).

## 🚀 تشغيل المشروع محلياً

```bash
dotnet run
```
ثم افتح المتصفح على الرابط المطبوع في الطرفية:
`https://localhost:7058` أو `http://localhost:5069`

---

## 🐘 تشغيل قاعدة بيانات PostgreSQL

في ملف `appsettings.json`:
1. غيّر `"DatabaseProvider": "PostgreSql"`
2. ضع رابط الاتصال بقاعدتك في `"PostgreSqlConnection"`:
```json
{
  "ConnectionStrings": {
    "PostgreSqlConnection": "Host=localhost;Port=5432;Database=physioclinic_db;Username=postgres;Password=yourpassword"
  },
  "DatabaseProvider": "PostgreSql"
}
```

### أو التشغيل بنقرة واحدة عبر Docker Compose:
المشروع مجهز بملف `docker-compose.yml` يشغّل قاعدة بيانات PostgreSQL 16 وتطبيق الويب معاً:
```bash
docker compose up -d
```

## 🌐 خيارات النشر والاستضافة (Hosting)

- **Render.com:** ملف `render.yaml` جاهز للرفع بنقرة واحدة.
- **Docker / Linux VPS:** ملف `Dockerfile` مخصص للإنتاج.
- **MonsterASP.net / Windows Hosting:** دعم مباشر لـ .NET و PostgreSQL عبر Web Deploy.
